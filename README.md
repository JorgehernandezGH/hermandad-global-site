# Hermandad Global Servicios Migratorios — website

Public marketing site for Hermandad Global Servicios Migratorios, a 501(c)(3) nonprofit
in Texas. Single self-contained `index.html` (no build step, no dependencies).

Bilingual (English/Spanish). Includes the organization's Privacy Policy and Terms of Service.
Deployed as a static site; custom domain hermandadglobal.org.
